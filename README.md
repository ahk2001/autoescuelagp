# Autoescuela GP Albacete — Sitio Web Oficial

Landing page editorial de alta conversión para **Autoescuela GP Albacete** (*Centro de Formación y Autoescuela GP S.L.*), ubicada en Calle Imperial, 3 (esquina C/ San Juan), 02006 Albacete.

## Estructura del Proyecto

- `index.html`: Página principal en HTML5 semántico, CSS3 moderno (variables y Grid/Flexbox) y JavaScript vanilla ligero.
- `assets/`: Logotipo oficial, favicon, vídeos introductorios (`homedesktop.mp4`, `homemobile.mp4`), fotografía de fachada y formación en motocicleta.
- `vercel.json`: Cabeceras de seguridad HTTP (`HSTS`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`) y caché inmutable para `/assets/*`.
- `robots.txt` & `sitemap.xml`: Configuración base de indexación SEO.
- `docs/`: Documentación estratégica de mercado y datos de origen (`dossie_autoescola.md`, `dados.txt`).
